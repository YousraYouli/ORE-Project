# ORE Documentation Website 🌐

## 🎯 Project Overview
This project was created during my **2CP year** as part of a university assignment.  
It’s a **web documentation platform** for a new programming language called **ORE**, built using **Django**.

The goal was to practice web development fundamentals — creating routes, templates, and database models using Python and Django.

## 🧰 Technologies Used
- Python  
- Django Framework  
- HTML / CSS (for templates)
